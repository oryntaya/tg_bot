## О проекте
Телеграм-бот (@test777ald_bot, «TestBot»). Пользователь отправляет название города, бот отвечает:
- погода сейчас: описание, температура и «ощущается как», мин/макс за сегодня, влажность, ветер (м/с), давление (мм рт. ст.), осадки;
- часовой пояс города и текущее местное время;
- курсы USD, EUR, RUB, CNY к местной валюте страны города (список в `RATE_CURRENCIES`).

Поиск музыки: `/music запрос` ищет в Deezer, показывает до 5 кнопок с треками; по нажатию бот присылает 30-секундное mp3-превью (скачивает и отправляет файлом) и ссылку на полный трек в Deezer. Полные треки с YouTube (yt-dlp) делать не будем — нарушение авторских прав; легальная альтернатива на будущее — Jamendo API (нужен бесплатный `JAMENDO_CLIENT_ID`).

Нормы права РК: `/ст номер кодекс` (алиасы `/st`, `/law`), например `/ст 188 УК`, `/ст 50 коап`, `/law 1 gk`. Кодексы: УК, ГК (общая + особенная часть), ТК, КоАП. Бот присылает текст статьи (длинные режет на части по ~3500 символов), ссылку на adilet.zan.kz и дату выгрузки базы. Текст берётся из локальной SQLite-базы, сайт adilet сам не парсим (в его robots.txt запрещены API и массовая выгрузка, скачивание PDF требует входа в аккаунт).

Команды: `/start`, `/help`, `/music`, `/ст`.

## Стек
- Python 3.9, aiogram 3 (long polling), aiohttp, python-dotenv, babel (валюта по стране), tzdata.
- Окружение: `.venv/` в корне проекта.
- Внешние API без ключей: Open-Meteo (геокодинг и погода), open.er-api.com (курсы валют), Deezer (музыка). Данные курсов обновляются раз в сутки.

## Файлы
- `bot.py` — запуск, хендлеры (`/start`, `/help`, текст = город), пропуск сообщений, пришедших в офлайне.
- `weather.py` — поиск города, погода, часовой пояс, курсы валют; формирует HTML-текст ответа.
- `music.py` — поиск треков и превью через Deezer API (без ключа). Ссылки на превью подписаны и протухают, поэтому в `callback_data` (`mt:<id>`) хранится только id трека, а трек запрашивается заново при нажатии.
- `laws.py` — разбор PDF кодексов на статьи в SQLite (`data/laws.db`) и поиск статьи (`parse_query`, `get_article`). Исходные PDF лежат в `data/pdf/` (uk, gk_obsh, gk_osob, tk, koap), их пользователь скачал сам с adilet.zan.kz под своим аккаунтом. Обновить базу после замены PDF: `.venv/bin/python laws.py` (нужен `pypdf`), затем перезапустить бота. Из текста статьи убираются «Сноска.» в конце; названия кодексов/алиасы и ссылки на источники — в `CODES` и `ALIASES`.
- `requirements.txt` — зависимости.
- `.env` — `BOT_TOKEN` (в `.gitignore`, права 600). Токен не выводить в чат и логи.

## Важно знать
- Одновременно должен работать только один экземпляр бота, иначе Telegram вернёт `Conflict: terminated by other getUpdates request`.
- Сообщения, написанные пока бот был офлайн, игнорируются: при старте `skip_offline_updates` подтверждает очередь у Telegram. В логе при этом строка «Пропущены сообщения…» или «Сообщений, пришедших в офлайне, нет».
- Из среды Claude Code запросы к `api.telegram.org/bot…` уходят в таймаут, поэтому бота запускает сам пользователь у себя в терминале; не запускать второй экземпляр (будет конфликт).
- Если сервис курсов недоступен, блок курсов просто не показывается; сбой сервиса погоды даёт пользователю сообщение об ошибке.
